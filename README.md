# 🏠 HomeFix – Home Service Booking App

**HomeFix** is a mobile-based home service booking application designed to connect customers with reliable home service providers such as plumbers, electricians, cleaners, carpenters, painters, and appliance repair technicians.

This is a **group project developed for the Human-Computer Interaction (HCI) module at SLIIT**.

## 🎯 Objectives

* Simplify finding and booking home services
* Help users find reliable service providers
* Provide service and pricing information
* Support standard and emergency bookings
* Enable ratings and reviews
* Track booking status
* Enable customer–provider communication

## ✨ Key Features

* 🔐 User Registration & Login
* 🔍 Service Search & Categories
* 👨‍🔧 Service Provider Profiles
* ⭐ Ratings & Reviews
* 💰 Service & Pricing Information
* 📅 Service Booking
* 🚨 Emergency Booking
* 📋 Booking Status Tracking
* 💬 Customer–Provider Chat
* 💵 Cash Payment Confirmation
* 📊 Admin Dashboard & Reports

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash

```

### 3. Install Dependencies

```bash

```

### 4. Run the Application

```bash
flutter run
```
